# AI Usage Report

## Tool used

OpenAI Codex helped plan, write, and check this portfolio.

## Tasks where AI helped

- Read the assignment and extracted personal details from the supplied resume.
- Generated the HTML, CSS, and JavaScript.
- Added form validation, the theme toggle, the greeting, and welcome feedback.
- Simplified the first design after the user asked for a basic training project.
- Drafted documentation and ran browser checks.

## Representative prompts

- "first see this and lets get to a plan and then proceed"
- "I will just share my resume"
- "use placeholders for links"
- "The thing u created is a bit more advanced , this is our basic training , So It would be better if the final protofolio is just at the requirements not above requirements"

## Code retained, changed, or removed

The current HTML, CSS, and JavaScript were generated by Codex. The personal details and four project descriptions come from the resume.

The first version included decorative illustrations, four projects, an extra Experience section, automatic section tracking, and saved theme preferences. The user considered that version too advanced, so these were removed during simplification. The user later requested four projects and current-section navigation again. The current version uses five sections, simple Grid and Flexbox layouts, a dark-theme CSS class, and JavaScript functions and conditions.

This report does not claim that the user independently reviewed every generated line.

## Issues and corrections

The main issue was scope: the first version went beyond the needs of basic training. The implementation was rewritten to match the assignment more closely. An unnecessary empty CSS import in the initial version was also removed during development.

During the final audit, Codex found that the primary button hover colors could make the buttons blend into the page. The hover colors were corrected, duplicate CSS was removed, and an outdated navigation comment was updated.

## Verification

Codex checked JavaScript syntax and used Playwright with installed Microsoft Edge to exercise navigation, welcome feedback, all three greeting branches, both themes, invalid and valid form input, and repeated submissions. Responsive checks covered 320, 375, 768, and 1440 pixels. Screenshots of the simplified layout were reviewed locally.

Playwright is a development testing tool only and is not part of the website. The final site runs with HTML, CSS, and vanilla JavaScript. The user can repeat the manual checklist in the README.

## Visual refinement

The user requested more style through colors and layout without extra components. Codex updated the palette to ivory, plum, and coral, adjusted typography and spacing, and arranged the existing sections in responsive columns. No new sections or JavaScript functionality were added. The existing browser checks passed again, and updated light, dark, and mobile screenshots were reviewed locally.

## Monochrome revision

The user requested a minimal black-and-white design without boxes and asked about tablet and mobile layouts. Codex replaced the colored backgrounds, skill badges, and project card borders with open sections, text rows, and thin dividers. The required dark theme reverses black and white. Existing content and JavaScript were retained. Browser checks were repeated at mobile, tablet, and desktop widths, including 820px and 1024px tablet layouts.

## Content and navigation update

At the user's request, Codex added two more resume projects, updated the skills list, included technology names in the project descriptions, added current-section navigation, and changed the required-field indicators and Welcome button styling. The user later requested removing the footer, then asked to restore it to meet the assignment requirement.
